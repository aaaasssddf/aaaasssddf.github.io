# MIPS的语法规范 
MIPS程序是由MIPS指令集中的指令构成的，MIPS的指令一般来说长这样：  
```mipsasm
addi $a0, $a0, 1
```
它相当于高级语言中的这样一个语句（以C语言为例）：  
```cpp
i = i + 1
```
我们还有更多MIPS指令，比如  
```mipsasm
j loop
beq $t0, $t1, finish
div $t0, $t1
```
相信看到这你也看出MIPS语句的一些共同特点了：它们都由一个助记符开始，然后后面跟着一些以逗号隔开的参数，它们以行为单位，而且最后每行的最后不需要分号。  
在这当中能看到许多含有$的参数，它们表示一个寄存器，寄存器里面可以用来保存数据、地址等内容。
# 寄存器
在高级语言中当我们创建一个变量的时候，系统会自动分配一个位置来储存它，所以我们在使用的时候只需要用它的变量名，系统就可以找到它。但是在MIPS中不一样，我们调用时会直接写出寄存器，然后机器直接去对应的寄存器取得数据（所以建议编写代码时注释好哪个寄存器对应着什么变量） 

MIPS 结构体系当中定义了 32 个寄存器，在使用的时候我们可以用寄存器的名称（如`$v0`）或者编号（如 `$1`），当然一般用前者能让代码可读性高一些。每一个寄存器都有对应的作用，我们在使用它们时应该遵循相应的规范。  

| 编号 | 寄存器别名 | 主要用途 |
|---|---|---|
| `$0` | `$zero` | 恒为 0，写入无效 |
| `$1` | `$at` | 汇编器临时寄存器，用于展开伪指令 |
| `$2～$3` | `$v0～$v1` | 函数返回值 |
| `$4～$7` | `$a0～$a3` | 前 4 个函数参数 |
| `$8～$15` | `$t0～$t7` | 临时寄存器，调用者保存 |
| `$16～$23` | `$s0～$s7` | 保存寄存器，被调用者保存 |
| `$24～$25` | `$t8～$t9` | 临时寄存器，调用者保存 |
| `$26～$27` | `$k0～$k1` | 内核保留寄存器 |
| `$28` | `$gp` | 全局指针 |
| `$29` | `$sp` | 栈指针 |
| `$30` | `$fp / $s8` | 栈帧指针；不用作帧指针时可作为保存寄存器 |
| `$31` | `$ra` | 函数调用的返回地址 |

在刚开始接触程序时用的比较多的是v、a、t、s，后面也会接触`$ra`、`$sp`等。需要注意的是虽然t和s在程序运行时并没有差异，但是我们最好还是按照对应的规则去维护。
# 程序的运行顺序以及标签
一般来说，MIPS的运行顺序是按写入的指令顺序从上到下的，但是基本的运行顺序并不能实现更复杂的功能，这就需要流程控制了。在MIPS中我们使用标签和条件分支、跳转类的指令实现流程控制，实现高级语言中的``if-else``、``for``之类的功能。  
在上面的内容中我们提到了`j loop`这条指令，这里的`loop`就是一个标签，我们一般这样写  
```mipsasm
loop:
#这里写指令
```
那么我们在别的地方使用`j loop`，就会跳转到loop标签的位置，程序就会从这个位置向下继续运行。（标签的名字可以自己随便取，只要知道是用来干啥的就行了）。  
特别地，我们可以会在程序的开始使用`main：`标签。
# 常用指令
## 运算
这里可以记一下，三个参数的指令，第一个是结果要保存到的寄存器。两个参数的指令就要用到hi和lo
### 加减

```mipsasm
add $s0, $s0, $s1
addi $s0, $s0, 1
addu $s0, $s0, $s1
addiu $s0, $s0, 1
```
add指令的意义是把后两项的值加起来，存到第一个参数的寄存器上，addi是的第三个参数是一个立即数，机器不用从寄存器中读取，而是命令中就已经包含了这个数（在Mars中，直接写add也可以用这种形式的参数），在前两个指令之后加个u表示无符号整数。
```mipsasm
sub $s0, $s0, $s1
subi $s0, $s0, 1 
subu $s0, $s0, $s1
subiu $s0, $s0, 1
```
减法的指令同理，这里就不多赘述了，只需要注意这里的减法顺序是第二个参数减去第三个参数，以及subi和subiu是可使用的伪指令，直接写sub也可以。

### 乘除
乘法可能产生超过32位数的结果2，整数除法会有商和余数两个结果，这个时候就需要用到hi和lo两个寄存器了。
标准MIPS指令集中的乘法是这么写的：
```mipsasm
mult $s0, $s1
multu $s0, $s1
```
两个32位整数相乘产生一个最多可能是64位的整数，这个乘积的高32位会放在hi，低32位会放在lo，要获取值可以使用mfhi和mflo：
```mipsasm
mfhi $s2
mflo $s2
```
这两个命令可以将hi和lo的值复制出来。  
同样的，除法：
```mipsasm
div $s0, $s1
divu $s0, $s1
```
其中余数储存在hi，商存在lo（不要记错了）。
除此之外还有一些伪指令，在你保证不会出问题的时候可以使用（但不是很建议）：
```mipsasm
mul   $t0, $t1, $t2    # 有符号乘法，$t0 = $t1 × $t2，保留乘积低 32 位；
mulu  $t0, $t1, $t2    # 无符号乘法，保留乘积低 32 位
mulo  $t0, $t1, $t2    # 有符号乘法；结果超出 32 位有符号范围时触发异常
mulou $t0, $t1, $t2    # 无符号乘法；结果超出 32 位无符号范围时触发异常
div   $t0, $t1, $t2    # 有符号除法：$t0 = $t1 / $t2，商向 0 截断
divu  $t0, $t1, $t2    # 无符号除法：$t0 = $t1 / $t2，取整数商
rem   $t0, $t1, $t2    # 有符号取余：$t0 = $t1 % $t2；非零余数与被除数同号
remu  $t0, $t1, $t2    # 无符号取余：$t0 = $t1 % $t2
```
这些的第三个参数都可以换成立即数，不过一般来说用两个参数的乘法和除法以及mfhi、mflo就可以了。
### 位运算
```mipsasm
and  $t0, $t1, $t2    # 按位与：$t0 = $t1 & $t2；
or   $t0, $t1, $t2    # 按位或：$t0 = $t1 | $t2；
xor  $t0, $t1, $t2    # 按位异或：$t0 = $t1 ^ $t2；
nor  $t0, $t1, $t2    # 按位或非：$t0 = ~($t1 | $t2)

sll  $t0, $t1, 2      # 逻辑左移 2 位，低位补 0
srl  $t0, $t1, 2      # 逻辑右移 2 位，高位补 0
sra  $t0, $t1, 2      # 算术右移 2 位，高位补原符号位
#这三个指令的第三个必须是立即数

sllv $t0, $t1, $t2   # 逻辑左移，低位补 0
srlv $t0, $t1, $t2   # 逻辑右移，高位补 0
srav $t0, $t1, $t2   # 算术右移，高位补原来的符号位
#这三个指令用t2的最低5位取代前面三个的立即数
```
这部分似乎在写程序的时候用的不多，设计cpu可能会见到。
## 条件分支
条件分支指令一般以b开头（Branch），最后一个参数是一个标签，其基本功能为满足对应的条件时跳转到对应标签的位置。
基本指令有以下几个：
```mipsasm
beq  $t0, $t1, label   # $t0 == $t1 时跳转
bne  $t0, $t1, label   # $t0 != $t1 时跳转
bltz $t0, label        # $t0 <  0 时跳转
blez $t0, label        # $t0 <= 0 时跳转
bgtz $t0, label        # $t0 >  0 时跳转
bgez $t0, label        # $t0 >= 0 时跳转
```
除了基本指令，Mars还提供了一些更常用的条件分支伪指令：
```mispasm
beqz $t0, label        # $t0 == 0 时跳转，等价于 beq $t0, $zero, label
bnez $t0, label        # $t0 != 0 时跳转，等价于 bne $t0, $zero, label

blt  $t0, $t1, label   # $t0 <  $t1 时跳转
ble  $t0, $t1, label   # $t0 <= $t1 时跳转
bgt  $t0, $t1, label   # $t0 >  $t1 时跳转
bge  $t0, $t1, label   # $t0 >= $t1 时跳转
```
三个参数的指令，在Mars中支持将第二个参数换为立即数；而且最后四个伪指令也可以加上u，表示无符号数的比较条件分支。 
记忆这一部分指令可以从其含义的英文入手，这些指令就是less、greater、equal、than之类的组合缩写。
## 跳转
最常用的是这个：
```mipsasm
j label
```
表示无条件跳转到某个位置，类似c中的goto语句。
用j指令可以实现简单的条件判断和循环结构了，在后面编写函数的时候，我们还会用到以下几个:
```mipsasm
jal func        # 跳转到 func，并将返回地址保存到 $ra
jr   $ra        # 跳到 $ra 保存的地址，常用于函数返回
jalr $ra, $t0   # 跳到 $t0 保存的地址，并将返回地址保存到 $ra
```
## 伪指令
MIPS指令集包含了一定的基础指令，而我们有时候会使用一些不在基础指令集中的指令以增强可读性或者简化代码的编写。可以用的伪指令都是能被基本指令集中的指令集实现的（上文就有很多简化过的伪指令），它们会被Mars转化为对应的基本指令再进行编译，一般常用的伪指令还有以下几条：
```mipsasm
li $s0, 1 #表示给一个寄存器赋一个立即数的值（很常用）

move $s1, $s0 #表示将s0的值复制到s1中，注意这里是复制，s0中的值不会消失
```
## syscall的使用
syscall 是 MIPS 指令集中的基本指令，用于触发系统调用异常。MARS 对它提供了模拟服务，通过 $v0 中的服务编号选择输出、输入、退出等操作。这些服务编号属于 MARS 的运行环境约定，不是 MIPS 指令集统一规定的。
所以在syscall之前经常会看见给v0赋值的`li`指令。下面是你可能最常用到的几个： 

| 服务编号 `$v0` | 功能 | 输入参数 | 返回值 |
|---|---|---|---|
| 1 | 输出整数 | `$a0`：要输出的整数 | 无 |
| 4 | 输出字符串 | `$a0`：以空字符结尾的字符串地址 | 无 |
| 5 | 读取整数 | 无 | `$v0`：读入的整数 |
| 8 | 读取字符串 | `$a0`：缓冲区地址；`$a1`：缓冲区容量，包含结尾空字符的位置 | 字符串写入缓冲区 |
| 10 | 退出程序 | 无 | 无 |
| 11 | 输出字符 | `$a0`：字符编码，使用低 8 位 | 无 |
| 12 | 读取字符 | 无 | `$v0`：读入的字符编码 |

在第一次作业中，可能知道1、5、10就可以了。字符串的输入输出后面再写。
读入的时候，整数和字符会写入v0寄存器，你可以使用move把它移到别的位置。输出的时候，记得先把要输出的内容移到a0寄存器中。
结束一个程序的时候就用10。
