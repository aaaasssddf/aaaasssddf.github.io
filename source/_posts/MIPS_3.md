# 宏
在编写MIPS的过程中，我们可能会觉得，某些非常简单的功需要反复写非常麻烦，搞不好还会把自己的思路扰乱。
我们接下来介绍宏，这个东西很实用，它可以帮我们把一些需要反复使用的代码片段封装，方便我们调用。例如输入、输出和结束程序，我们再也不用写好几行指令，而是可以用简单的一行调用来完成。
一个宏的定义由`.macro`和`.end_macro`包围，下面展示一个宏作为例子：
```
.macro READI(%i)
    li $v0, 5
    syscall
    move %i, $v0
.end_macro 
```
这个宏实现了读取某一个整数的功能，我们借此观察宏定义的语法结构。在`.macro`后面写宏的名字，以及用括号包裹需要用到的参数。这里编译器并不会校验`%i`的类型，只是在预处理的时候机械地将宏替换到调用宏的位置，然后将传入的`%i`复制到对应的位置。也就是说，在实现一个宏的过程中，参数可以是立即数、标签、寄存器等。你需要保证在宏内部实用指令时参数类型合法。
这就像c语言的`#define`：
```
#define max(a, b) ((a > b) ? a : b)
```
在这个定义中，编译器也不会去校验`a`和`b`是`int`还是`long long`或者`double`。
不仅如此，宏也可以嵌套使用，只要宏里面调用的宏也是存在且合法的。
在这篇文章中，我写了一些很有用的MIPS宏，可以在编写代码时复制在开头直接使用。 {% post_link MIPS_extra %}
# 函数
在MIPS中，一般约定`$v0`、`$v1`作为函数返回值寄存器，以及`$a0 ~ $a3`作为函数参数寄存器。
我们用一个标签来表示函数的开始，在结尾使用`jr $ra`返回原来的位置。调用函数时要使用`ja label`，这样会将调用时的指令地址储存在`$ra`中。
一个例子，实现`f(x) = x + 1`：
```mipsasm
#我们约定将a存在$a0，返回值存在$v0
function:
    add $v0, $a0, 1
    jr $ra
```
调用求`f(3)`
```mipsasm
li $a0, 3
jal function
```
程序会跳转至`function`，然后执行完后跳转回`jal function`这条指令的位置，继续执行后面的代码，返回值存在了`$v0`中。
# 栈与递归
## $sp指针及其使用
在程序设计的学习中我们可能已经认识到了**栈**这个概念。简单来说，栈是内存中一块用于储存临时数据的空间。在MIPS的寄存器中，`$29`对应`$sp`，即栈顶指针。在MIPS的调用约定中，栈的空间向**低地址**增长。当我们将`$sp`储存的地址值减小时，多出的这部分空间可以用于储存数据，而将`$sp`的值增大会释放这一部分栈空间。每次函数调用分配的那部分空间称为**栈帧**。这里分配空间的单位是**字节**，也就是分配储存一个整数的空间需要使`$sp`减少`4`。
```mipsasm
addiu $sp, $sp, -8 # 这个指令分配了8个字节的栈空间

sw $t0, 0($sp) # 将$t0的数据存到栈中
sw $t1, 4($sp) 

lw $t0, 0($sp) # 将栈空间中的数据读取写入$t0
lw $t1, 4($sp)

addiu $sp, $sp, 8 # 释放8个字节的栈空间
```
## 递归
这个上机不考，但是课下实验有一个这个题（其实这题分值为0）。这里就简单贴下代码，不仔细讲了。总之，递归仍然遵循`$a0 ~ $a3`作参数，`$v0 ~ $v1`作返回值的规律，但是每次递归调用需要向栈里储存数据，递归调用结束需要恢复数据，并且每一层递归一定要有分配栈空间然后进行递归操作然后再释放栈空间的过程。每层的栈中需要储存的数据有当前的参数、调用当前递归函数的地址，以及如果函数每一层要多次递归的话，还需要额外储存前面递归的返回值。
```mipsasm
function: #a0为n, a1为m, v0为返回值
        beqz $a0, ret
        beqz $a1, ret
        addiu $sp, $sp, -16 #每层需要保存参数、返回值、地址
        
        #栈约定：0、4为参数，8暂存返回值，12地址
        sw $a0, 0($sp)
        sw $a1, 4($sp)
        sw $ra, 12($sp)
        
        # 第一次递归
        addi $a0, $a0, -1
        jal function
        # 此时第一个返回值在$v0中，我们将其暂存到栈中
        sw $v0, 8($sp)
        
        lw $a0, 0($sp)
        lw $a1, 4($sp)
        
        # 第二次递归
        addi $a1, $a1, -1
        jal function
        # 此时第二个返回值在$v0中，第一个返回值在8($sp)
        
        move $t0, $v0
        lw $t1, 8($sp)        
        lw $a0, 0($sp)
        lw $a1, 4($sp)
        mul $t2, $a0, $a1
        add $t2, $t2, $t0
        add $t2, $t2, $t1
        
        move $v0, $t2
        lw $ra, 12($sp)
        # 恢复上次调用的地址
        addiu $sp, $sp, 16
        # 释放本层新分配的栈空间
        jr $ra
       
    ret:
        li $v0, 1
        jr $ra
```
