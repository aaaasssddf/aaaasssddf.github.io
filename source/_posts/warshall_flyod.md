# Warshall（沃舍尔）算法
Warshall算法是一种通过布尔矩阵的迭代更新求解有向图或者关系矩阵的传递闭包的算法。
## 概念
- 传递闭包：包含原关系 $R$ 的最小传递关系。对有向图而言，它包含所有满足“存在从 $u$ 到 $v$ 的正长度路径”的有序节点对 $(u,v)$。
- 布尔矩阵：如果关系 $R$ 使得 $xRy$ ，那么矩阵中 $R[x][y] = 1$ ，否则 $R[x][y] = 0$ 。  

## 问题
- 输入：整数 $N$ 表示节点数量， 以及一个 $N * N$ 的矩阵，只包含1和0，表示一个关系对应的布尔矩阵（有向图的邻接矩阵）。
- 输出：一个 $N * N$ 的矩阵，表示传递闭包。  

也就是说，任意 $1 <= a,b,c <= N$ 如果输入中有 $R[a][b] = R[b][c] = 1$ ，输出中就有 $R[a][c] = 1$ 。

## 原理与代码
通过中间节点逐步更新可达性。外层循环 $k$ 表示轮次，在第 $k$ 轮中，更新$ i \to j$是否有可达关系：
$$ R[i][j] = R[i][j] \lor (R[i][k] \land R[k][j])  $$
**为什么这个迭代顺序可以求出所有的可达关系？**
在第 $k$ 轮外层循环完成时，$R$表示的是允许来自前$k$个节点的节点作为中间节点的所有可达关系。例如存在 $ a \to b \to c \to d$这条路径，假设 $b < c$，那么在第 $b$ 轮更新时就能确定 $a$ 可达 $c$ ，到了第 $c$ 轮的时候，矩阵中已经有 $R[a][c] = 1$，那么就可以确定 $a$ 可达 $d$ 。如果 $c$ < $b$ 呢？那么 $b \to d$会先被加入矩阵，到第 $b$ 轮时就可以确定 $a \to d$ 。简单来说，最外层的循环是从 $1$ 到 $N$ **逐步扩大允许中间节点存在的范围的过程**。
代码如下（c++):
```cpp
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            reach[i][j] = reach[i][j] || (reach[i][k] && reach[k][j]);
```
** 时间复杂度为 $O(n^3)$ ，空间复杂度为 $O(n^2)$ 。**
# Floyd（弗洛伊德）算法
Floyd算法也叫Floyd-Warshall算法。用于求解一个有向图中任意两点之间的最短路径。在上文中，我们已经总结了为什么Warshall算法的迭代顺序可以求出所有可达关系，我们进一步地利用这种思想，只不过将关系矩阵换成储存了边的权值的邻接矩阵，结合动态规划，就可以解决这个问题。
## 要求
- 有向图和无向图均可，允许负权边，但是不允许有限最短路径经过负权环。若要得到所有可达节点对的有限最短距离，图中不能存在负权环。若存在负权环，则所有能够经过该负环到达终点的节点对，都不存在有限最短距离。
- 正确初始化矩阵：无边的设置为`INF`，要求`dist[i][i] = 0`，有重边的时候用最小边权。 

## 原理与代码
采用与Warshall算法一样的迭代顺序：第 $k$ 轮更新允许 $i$、$j$之间存在来自 $ \{1,2,...,k\} $ 的节点作为中间节点的最小距离，如果存在比之前轮次更小的结果，就将其更新。其迭代方程为:
$$ D^{(k)}[i][j] =\min\left\{D^{(k-1)}[i][j],\;D^{(k-1)}[i][k] + D^{(k-1)}[k][j]\right\},\qquad k=1,2,\ldots,n. $$
**为什么符合动态规划最优子结构的要求？**
若一条从 $a$ 到 $c$ 的最短路径经过 $b$，则它从 $a$ 到 $b$、从 $b$ 到 $c$ 的两段子路径，也分别是对应端点之间的最短路径；否则可以替换其中一段，得到更短的整体路径，产生矛盾。
**为什么k要放在迭代的最外层？**
第 $k$ 轮只允许前 $k$ 个节点作为中间节点。最短路径若不经过 $k$，沿用上一轮结果；若经过 $k$，就在 $k$ 处分成两段，两段内部都只允许使用前 $k-1$ 个节点。取两种情况的较小值，就得到本轮答案。因此 $k$ 必须放在最外层。
**代码如下：**
```cpp
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            if (dist[i][k] != INF && dist[k][j] != INF)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
```
其复杂度与Warshall算法一致。**时间复杂度为 $O(n^3)$ ，空间复杂度为 $O(n^2)$。**
